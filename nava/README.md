# NAVA — آواتار زنده فارسی

نسخهٔ رابط کاربری مرجع NAVA برای پروژهٔ barghchee. مسیر این نسخه: `/nava/`.

## امکانات
- رابط فارسی راست‌چین با تصویر مرجع، پنل مکالمه، موج صوتی و کنترل‌های تماس.
- تشخیص گفتار فارسی در مرورگرهای پشتیبان Web Speech API و پاسخ صوتی با SpeechSynthesis.
- چت متنی با FastAPI و OpenRouter؛ کلید API فقط در سرور نگهداری می‌شود.
- وضعیت شنیدن/فکرکردن/صحبت‌کردن و کنترل قطع میکروفون و پخش صدا.

## اجرا
1. در ریشهٔ مخزن: `npm install` و سپس `npm run dev`.
2. در ترمینال دیگر: `cd nava/backend`، محیط مجازی بسازید، `pip install -r requirements.txt` و `uvicorn main:app --host 0.0.0.0 --port 8000`.
3. برای توسعه، Vite را به API با proxy یا از طریق reverse proxy متصل کنید؛ در این نمونه API در پورت 8000 است. `VITE_API_BASE=http://localhost:8000` را در `nava/.env.local` قرار دهید.
4. تصویر ارائه‌شده در این گفتگو را با نام دقیق `مرجع.png` در همین پوشهٔ `nava/` قرار دهید.

## تنظیم OpenRouter
فایل `nava/backend/.env.example` را به `.env` کپی و `OPENROUTER_API_KEY` را تنظیم کنید. هرگز کلید را داخل فایل‌های فرانت‌اند قرار ندهید.

## محدودیت‌های فنی صادقانه
این نسخه رابط و لولهٔ مکالمهٔ صوتی مرورگری را فراهم می‌کند؛ صدای ورودی به‌وسیلهٔ Web Speech API مرورگر به متن تبدیل می‌شود و پاسخ با گفتار مرورگر خوانده می‌شود. این روش **Full-Duplex واقعی، قطع گفتار مدل در سطح فریم صوتی، WebRTC صوتی به مدل، ریگ سه‌بعدی، همگام‌سازی واج‌به‌واج لب یا بازسازی هندسهٔ چهره را پیاده‌سازی نمی‌کند**. برای آن‌ها باید مدل سه‌بعدی rigged (مثلاً GLB با morph targets) و سرویس گفتار/Realtime سازگار جداگانه متصل شود. تصویر مرجع به‌تنهایی هندسهٔ سه‌بعدی یا ریگ تولید نمی‌کند.
